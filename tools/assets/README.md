# Guide artwork and fonts

The PDF editions use the Travel Monkey Field Guide palette and the original monkey
mark, copied from the app's `design/assets/monkey-mark.png`. Fraunces and Karla are
copied from the app's bundled font resources, with their SIL Open Font Licenses.

Noto Sans Symbols supplies the arrows and information symbol on every platform.
Its source is Google Fonts (`ofl/notosanssymbols/NotoSansSymbols[wght].ttf`) and its
SIL Open Font License is included beside it. Fonts are bundled so rebuilding needs
no font download, neighboring repository, or operating-system-specific font.

The editable editions use Georgia and Arial so Google Docs can preserve their
typography with standard fonts. All screenshots come from the support repository's
`images/` folder. Demonstration data and source captions remain intact.
